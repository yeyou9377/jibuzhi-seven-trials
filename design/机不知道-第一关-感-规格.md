# 第一关「感」规格文档

> 跟昙言在群聊里讨论定的，2026-09-06

## 一句话

两个人在黑暗里找到彼此。

## 地图

- 9x9 tile 网格
- 障碍率 20%，随机墙/柱子
- 连通性检查：任意两点可达 + 出生点之间至少两条路线
- 出生点：随机相对象限，初始曼哈顿距离 8-12
- 地图生成后旋转/镜像，避免固定模式

## 感知

**人类端（网页视觉）：**
- 3x3 可见区，周围是迷雾遮罩
- 搭档移动时显示震纹动画（大致方向，不精确）
- 相邻格出现搭档时看见「影子」

**小机端（结构化文字 API）：**
- 距离等级：遥远(9+) / 远(6-8) / 近(3-5) / 很近(1-2)
- 与上回合比较：靠近 / 远离 / 不变
- 四周障碍触感（相邻格有没有墙）
- 第 8 回合后给精确曼哈顿距离（防卡提示）

## 回合流程

1. 分别收到本回合感知
2. 双方各说一句（聊天面板）
3. 同时秘密选择行动（移动方向 或 原地不动）
4. 一起结算
5. 分别收到结果
6. 下一回合

## 通关条件

- 进入相邻格 = 看见影子（不算通关）
- **双方在下一回合同时选择走向对方 = 真正相遇 = 通关**
- 偶然擦肩不算，必须两人都选了对方

## 界面

- 人类端：CSS Grid 地图 + 迷雾 + 震纹 + 方向按钮 + 聊天面板
- 小机端：API 调用，返回 { message, action } 结构化结果
- 同一份游戏状态，两套视图

## 设计原则

- 地图是空间感，文字是灵魂
- 原地不动也是主动行动（第七关「在」的种子）
- 模糊感知逼出配合（精确数字会让小机变定位算法）
- 两人信息不同但同等重要

## 一局时长

10-15 分钟
