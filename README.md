# 七味 · 一味决明

《七味》人机配对叙事游戏的第一味可玩原型。

## 试玩

直接打开 `index.html`，或在目录中运行：

```bash
python3 -m http.server 4173
```

再访问 `http://localhost:4173`。

当前版本由本地规则驱动“无名灵伴”，让单人也能完整体验第一关。游戏状态已经将人类感知与小机感知拆开，后续可以替换为论坛配对与模型 API。

## 核心体验

- 金瞳 / 银瞳的开局选择；
- 9×9 连通随机地图与局部视野；
- 小机仅获得模糊距离、距离变化和邻近障碍；
- 双方同时行动，10 回合内在黑暗中相遇；
- 神庙会模仿玩家的话，但回声只能复述过去；
- 通关后共同命名相遇之地，并取得决明子。

药性文字仅用于文化与游戏设定，不构成诊疗或用药建议。
